# v1.2.5 — Refresh Python and Debian base images

Rebuild reader and dashboard-backend in GitHub Actions with the current
`python:3.15-slim-trixie` base. Release builds explicitly pull their base image;
the Python minor version and Debian series are fixed to avoid unexpected major
runtime or distribution upgrades. Tests run on Python 3.13 and 3.15.

No application code or database schema changes. Existing schema-3 UTC storage,
Europe/Berlin dashboard calendars, healthchecks and memory limits are preserved.
Upgrades from v1.2.4 do not require a database migration. Older installations
must still follow the schema-3 migration instructions before upgrading.
